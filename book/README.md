## PDF exports

Both PDFs contain **544 pages** and embed the Origin typefaces. The
LibreOffice export is approximately **3.94 MB**. The Microsoft Office export
is approximately **2.90 MB** and was produced using “Save as PDF” in Microsoft
Word for Microsoft 365 from the DOCX with stable fraction artwork. These sizes
use decimal megabytes.

All seven stacked fractions display correctly in both PDF exports. In addition
to their visible artwork, the LibreOffice PDF includes searchable fraction
values. The Office export preserves the visible fraction artwork, but those
fractions may not copy or search as ordinary text.

## EPUB edition

The EPUB is a **reflowable EPUB 3** edition built from the corrected DOCX.
It embeds the Regular, Italic, and Small Caps Origin fonts, version 1.00, and
includes the preliminary matter, all 14 chapters, the branching diagram,
the original index, and the publisher’s catalogue.

It provides a chapter navigation menu and a page list linked to the original
printed pages. Numeric index references link to those page locations. Line-end
hyphenation and paragraph continuations are joined for reading; the device’s
font size and screen width determine the displayed page layout. Running headers
and the blank reverse of the diagram are omitted. The diagram remains an image.

Fractions are represented as ordinary text, including `6 3/4 ounces`, rather
than Word equation fields. Font and paragraph settings can be overridden by
the reading application. The EPUB passes EPUBCheck with no errors or warnings;
this does not constitute exhaustive proofreading of the historical text.

## Contents and layout

The 544-page reconstruction includes preliminary pages, numbered main text,
the folded branching diagram after printed page 168, its blank reverse,
the index through printed page 502, and the 32-page publisher’s catalogue.
PDF page numbers therefore differ from the book’s printed page numbers.

Text pages are typeset text, rather than photographs with an invisible OCR
layer. The diagram and its reverse retain their scanned appearance. Source
paper discoloration and handwritten marks on text pages are omitted.

The layout follows the original printed pagination and line arrangement,
with justified prose, appropriate separate treatment of the title, contents,
index, and catalogue, and odd/even running headers with page-number fields.
Horizontal rules, small caps, italic passages, and superscript references
are preserved where reconstructed. Historical spelling and punctuation spacing
are retained rather than systematically modernized.

## Editing

Install the fonts from [fonts/ttf](../fonts/ttf) before editing. The document
also embeds them, but application support for embedded fonts varies.

The DOCX uses native paragraphs and page sections with many deliberate line
breaks to retain the printed arrangement. It is editable, but is not designed
to reflow freely after large changes. Fonts, layout engines, field updates,
and printer settings can change pagination.

Compact stacked fractions in the DOCX use inline vector artwork with PNG
compatibility fallbacks and numeric alternative descriptions. They are fixed
artwork rather than editable equations. The LibreOffice PDF includes additional
searchable fraction values; a fresh PDF export can handle copying and searching
those graphics differently.

For the overall method, see [GENERATION.md](../docs/GENERATION.md).
Compare uncertain readings with the [source scans](../docs/SOURCES.md).
